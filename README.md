# A2A CLI

[![npm version](https://img.shields.io/npm/v/@a2anet/a2a-cli.svg)](https://www.npmjs.com/package/@a2anet/a2a-cli) [![License](https://img.shields.io/github/license/a2anet/a2a-cli)](https://github.com/a2anet/a2a-cli/blob/main/LICENSE) [![A2A Protocol](https://img.shields.io/badge/A2A-Protocol-blue)](https://a2a-protocol.org) [![Discord](https://img.shields.io/discord/1391916121589944320?color=7289da&label=Discord&logo=discord&logoColor=white)](https://discord.gg/674NGXpAjU)

A CLI for the [Agent2Agent (A2A) Protocol](https://a2a-protocol.org/latest/). Use it to connect to [A2A Servers (remote agents)](https://a2a-protocol.org/latest/topics/key-concepts/#core-actors-in-a2a-interactions) and send messages from your terminal.

## 📦 Installation

```bash
npm install -g @a2anet/a2a-cli
```

## 🚀 Usage

```bash
a2a --help
a2a --version
```
